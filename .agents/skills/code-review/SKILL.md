# Code Review Skill

When performing a code review, analyze the target code thoroughly against the following criteria:

## Review Checklist
1. **Correctness**: Does the code accurately solve the intended problem without logical bugs?
2. **Edge cases**: Are potential errors, null states, boundary limits, and exception conditions safely handled?
3. **Style**: Does the code adhere to established project conventions, naming standards, and formatting patterns?
4. **Performance**: Are there any blatant inefficiencies, heavy resource bottlenecks, or redundant computations?

## Feedback Guidelines
- Be direct, specific, and reference exact lines or blocks needing change.
- Explain the reasoning behind why a modification is suggested.
- Provide clean alternative code snippets where applicable.
